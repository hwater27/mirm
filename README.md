# Microstate Response Model

Official repository for *Microstate Response Model: A Unified IRT Framework from Latent Nominal States to a Theory of Tests*.

<img width="2340" height="792" alt="dip_math42_story" src="https://github.com/user-attachments/assets/869d0640-6381-4add-9ec0-d0b18f18856d" />

> **Note.** The code that reproduces the results of the paper is available in this repository (`./reproduce/`); an official package `./mirm/src/` is in preparation. The core model, estimation, and evaluation code was written mostly by the authors. A substantial part of the analysis, plotting, and run scripts and the data preprocessing code (by line count, roughly 80% of the analysis and plotting code, all of the preprocessing code, and about 70% overall) was written with the assistance of AI tools; all code was reviewed by the authors, and the results were checked. Some analysis code grew incrementally during the research and may be less organized than the core.
